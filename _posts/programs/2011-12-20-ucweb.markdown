Патч для UC Browser

Патч дозволяє використовувати функції "Закладки" та "Моя навігація" у версії 7.9.1.120 (Build 11120910), які в звичайному релізі для n-gage не працюють. 

Інструкція з установки:
- Скопіюйте папку System в корінь диска D.
- Відкрийте UC Browser, перейдіть до закладок, виберіть "Копії" – "Імпорт персональних даних/резервні закладки" і оберіть файл із розширенням .bak.
- Перезапустіть браузер.

Дякуємо yarig за патч!

Проксі для UC Browser

Для доступу до деяких сайтів, які можуть не завантажуватись, необхідно змінити проксі, замінивши оригінальний файл .uhtm.

Інструкція з установки:
- Скопіюйте файл UCSystemConfigure.uhtm у папку за шляхом E:\private\2001128D\.
- Підтвердіть заміну файлу.
- Після цього проксі буде налаштовано.
