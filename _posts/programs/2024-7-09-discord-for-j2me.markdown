На поки n-gage не тестувалось!

Discord-клієнт для пристроїв Java ME (MIDP 1.0 та 2.0), натхненний Discord для Symbian. Використовує проксі-сервери для підключення HTTP та шлюзу.

{:.img-center}
![Discord for J2ME](/n-gage/programs/screenshots.png)

Працює:

- Списки серверів та каналів
- Читання, надсилання, редагування, видалення повідомлень
- Відповіді на повідомлення
- Читання старіших повідомлень
- Прямі повідомлення та групові DM
- Перегляд вкладень
- Надсилання вкладень (залежить від пристрою)
- Оновлення через шлюз / живі повідомлення (залежить від пристрою)
- Індикатори непрочитаних повідомлень

Не реалізовано:

- Перехід до конкретних повідомлень (наприклад, на відповіді)
- Ініціювання DM-розмов
- Індикатори активності (Ping)
- Реакції та емодзі
