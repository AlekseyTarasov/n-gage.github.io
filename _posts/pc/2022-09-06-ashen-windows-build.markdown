Windows-версія гри Ashen для Nokia N-Gage, яка використовувалася Torus Games під час розробки гри. Дозволяє запускати декілька екземплярів у вікні для тестування багатокористувацького режиму гри.

Щоб запустити гру, необхідно просто відкрити файл exe, натиснути F8, і можна грати.

Управління встановлене на стрілки, Enter, Backspace та клавіші на «калькуляторі». Хоча переназначити їх можна лише в рамках цих клавіш через меню налаштувань гри, найзручнішим варіантом може бути використання джойпада разом із програмою типу joy2key для розширення контролю.

Для масштабування вікна гри можна скористатися клавішами PgUp/PgDn. Графічних фільтрів у збірці немає, що очікувано для девелоперської версії.
